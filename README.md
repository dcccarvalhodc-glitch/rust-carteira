\# Carteira de Investimentos em Rust



Projeto desenvolvido em Rust para gerenciamento de uma carteira de investimentos.



\## Tecnologias utilizadas



\- Rust

\- Axum

\- SQLx

\- PostgreSQL

\- JWT

\- Askama Templates



\## Funcionalidades



\- Cadastro de usuários

\- Autenticação com JWT

\- Gerenciamento de ativos

\- Controle de carteira de investimentos



\## Objetivo



Projeto desenvolvido como parte do desafio da Digital Innovation One (DIO), aplicando conceitos de desenvolvimento backend com Rust.
