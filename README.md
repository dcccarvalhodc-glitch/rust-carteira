# Carteira de Investimentos em Rust

Aplicacao Fullstack desenvolvida em Rust para gerenciamento de uma carteira de investimentos.

## Sobre o projeto

Este projeto foi desenvolvido como parte do desafio da Digital Innovation One (DIO), com o objetivo de praticar a criacao de uma aplicacao web completa utilizando Rust, API, banco de dados, autenticacao e interface web.

## Tecnologias utilizadas

- Rust
- Axum
- SQLx
- PostgreSQL
- JWT
- Askama Templates
- Docker

## Funcionalidades

- Cadastro de usuarios
- Autenticacao com JWT
- Gerenciamento de ativos
- Controle de carteira de investimentos
- Interface web com dashboard autenticado

## Melhoria implementada

Foi realizada uma melhoria no dashboard inicial da aplicacao, adicionando informacoes sobre o projeto e as tecnologias utilizadas, tornando a tela mais informativa para o usuario.

## Como executar o projeto

1. Clone o repositorio:

git clone https://github.com/dcccarvalhodc-glitch/rust-carteira.git

2. Execute a aplicacao:

cargo run

3. Acesse no navegador:

http://localhost:3000

## Como testar

- Realizar login na aplicacao;
- Verificar o carregamento do dashboard;
- Confirmar a conexao com PostgreSQL;
- Validar as funcionalidades disponiveis da API.

## O que aprendi

Durante o desenvolvimento deste projeto pratiquei:

- Estruturacao de uma aplicacao Fullstack com Rust;
- Criacao de rotas utilizando Axum;
- Integracao com PostgreSQL usando SQLx;
- Autenticacao com JWT e cookies;
- Uso de templates HTML com Askama;
- Versionamento utilizando Git e GitHub.
